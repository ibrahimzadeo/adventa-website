# Adventa Website

Astro.js website for Adventa - AI Consulting, Data Analytics & Speech-to-Text Solutions.

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Structure

- `src/pages/` - Page routes
- `src/layouts/` - Layout components
- `src/components/` - Reusable components
- `public/` - Static assets

- AI Consulting
